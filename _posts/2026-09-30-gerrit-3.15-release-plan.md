## High Level Release Plan

| Date       | Activity                                          |
|------------|---------------------------------------------------|
|   Oct  5   | Create `stable-3.15` branch, Release `3.15.0-rc0` |
|   Oct 12   | Release `3.15.0-rc1`                              |
|   Oct 19   | Release `3.15.0-rc2`                              |
|   Oct 26   | Release `3.15.0-rc3` - Feature freeze deadline.   |
|   Nov  2   | Release `3.15.0-rc4`                              |
|   Nov 9    | Release `3.15.0-rc5` - Release freeze             |
|   Nov 13   | Final release of `3.15.0`                         |

## Gerrit Hackathon

There will be a [Gerrit Hackathon following the User Summit 2026](https://gus26.gerritforge.com)
where the Gerrit maintainers will be able to get together and work side-by-side for three days
at [NVidia](https://www.nvidia.com).

## End-to-end Testing

We plan to use the
[Gatling e2e test framework for Git](https://gerrit-review.googlesource.com/Documentation/dev-e2e-tests.html),
developed by GerritForge and Ericsson to test the stability of the release
on a production-like setup.

## End of Life for Gerrit 3.12.x

Per the support policy mentioned in the
[project homepage](https://www.gerritcodereview.com/support.html#supported-versions),
after 3.15.0 is released, 3.12.x will reach the end of life and will no
longer be actively supported.

Support for 3.13.x and 3.14.x will continue as usual.
Users of 3.12.x or earlier are recommended to upgrade to one of these versions.
